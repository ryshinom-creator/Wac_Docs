▼7 · Conteúdo do documento

Esta barra põe no fim. Para colocar no meio, use as linhas “inserir aqui” que aparecem entre os blocos — elas têm os três níveis.
Texto: linha em branco separa parágrafos · - item lista · -- item sub-item · **negrito** · *itálico*.
Barra de Ferramentas: Use os comandos acima do editor de texto para injetar novas páginas A4 ou quebras estruturais.
Figuras (Word): arraste na prévia para mover ou use ALT + Arraste para posicionamento livre. Ajuste a escala puxando as alças azuis.
⇕ Um por vez: com o acordeão ligado (o padrão), abrir um bloco fecha o que estava aberto — a tela nunca fica cheia e não se perde o lugar.
Título do projeto: ao sair do campo, o nome novo substitui o antigo em todo o documento.
⊙ Auto: com o recolhimento automático ligado, cada bloco já preenchido se fecha sozinho quando você passa para o próximo — a tela vai ficando limpa conforme o documento avança.
🖨 Imprimir: imprime a prévia em A4 ou salva em PDF pelo próprio navegador, sem precisar do MiKTeX (útil para uma cópia rápida; o PDF do LaTeX continua sendo o melhor acabamento).
CTRL+Z / CTRL+Y: desfaz e refaz no documento inteiro (dentro de um campo de texto, o primeiro CTRL+Z desfaz só a digitação). CTRL+S salva o projeto.
Campos dinâmicos: {{CLIENTE}}, {{CIDADE}}, {{PROJETO}}… se atualizam sozinhos quando você troca a firma ou a unidade — o resto do texto fica intocado.
CTRL + ENTER: manda o texto (ou só o trecho selecionado) para a IA, que devolve a versão revisada no lugar. O seletor ✦ escolhe o quanto ela mexe: Revisar (só erros), Melhorar (padrão técnico) ou Desenvolver (elabora mais). Depois, o aviso traz 👁 ver o que mudou e ↶ desfazer.
＋ Capítulo / Seção / Subseção na barra do texto: cria o bloco a partir do cursor — o que estiver escrito depois dele vai junto para o bloco novo. Para criar em branco num ponto qualquer, use as linhas “inserir aqui” entre os blocos.
ALT + ENTER: quebra a linha sem começar um parágrafo novo (serve também na carta e na edição direta da prévia).
Proposta Técnica: os capítulos de nível 1 saem em MAIÚSCULAS e numerados (1. OBJETIVO), como manda o padrão.
Tabelas (Excel): Adicione tabelas visuais, gerencie suas grades de dados e use o marcador correspondente (ex: [T1]) no texto para indicar a posição exata.
